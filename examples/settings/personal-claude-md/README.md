## 설치
```bash
cp CLAUDE.md ~/.claude/CLAUDE.md   # 이미 있으면 내용을 합치세요
```

## 프로젝트용과의 차이
| | 개인용 `~/.claude/CLAUDE.md` | 프로젝트용 `./CLAUDE.md` |
|---|---|---|
| 내용 | 나의 말투·작업 습관 | 이 레포의 명령어·규칙 |
| 공유 | 안 함 | Git으로 팀과 공유 |
