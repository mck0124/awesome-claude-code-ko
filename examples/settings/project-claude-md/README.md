# 프로젝트용 CLAUDE.md 템플릿

## 무엇을 하나
Claude가 세션을 시작할 때마다 읽는 프로젝트 안내서입니다. 매번 같은 설명을 반복하지 않게 해 줍니다.

## 언제 쓰나
새 레포에서 Claude Code를 처음 쓸 때, 또는 Claude가 같은 실수(잘못된 테스트 명령, 규칙 위반)를 반복할 때.

## 설치
프로젝트 루트에 `CLAUDE.md`로 복사하고 **자기 프로젝트에 맞게 모두 고칩니다.** (`/init`으로 초안을 만든 뒤 이 구조에 맞춰 다듬어도 됩니다.)

## 작성 원칙
1. **Claude가 코드만 봐서는 알 수 없는 것**만 적습니다 (실행 명령, 금지 사항, 함정). 코드 구조 전체를 설명하지 않습니다.
2. 짧게 유지합니다. 길어질수록 지시가 흐려집니다. 길어지면 `@docs/규칙.md`처럼 파일로 나눕니다.
3. Claude가 실수할 때마다 한 줄씩 추가합니다.

## 검증
> ⚠️ 템플릿이라 측정 수치는 없습니다. 메인테이너가 직접 써 본 뒤 효과를 적을 예정입니다.
