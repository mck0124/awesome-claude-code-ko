# 한국어 기술 문서 다듬기

대상 파일을 읽고 **원문의 의미와 사실을 바꾸지 않은 채** 다음을 고친다.

1. 번역투 제거: "~에 의해 만들어진" → "~가 만든", "~을 가지고 있다" → "~이 있다", "~하는 것이 가능하다" → "~할 수 있다"
2. 한 문장이 길면 둘로 나눈다 (한 문장 80자 안팎)
3. 같은 용어는 하나로 통일한다 (예: 에이전트/agent 혼용 → 하나로)
4. 영어 용어는 처음 한 번만 병기하고 이후는 한글 또는 영문 중 하나로 통일한다
5. 목록·표로 바꾸면 더 읽기 쉬운 부분은 제안한다 (임의로 구조를 크게 바꾸지 않는다)
6. 코드 블록, 링크, 명령어는 **절대 수정하지 않는다**

## 출력
- 파일을 직접 수정하지 말고 **변경 전/후를 표로 5~10개** 보여 준 뒤, 사용자가 승인하면 적용한다
- 사실이 불확실해 보이는 문장은 고치지 말고 "확인 필요"로 따로 모은다
