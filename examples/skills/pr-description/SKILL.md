# PR 설명 작성

1. `git log main..HEAD --oneline`과 `git diff main...HEAD --stat`으로 범위를 파악한다. 필요하면 핵심 파일 diff를 읽는다.
2. 아래 템플릿으로 작성한다.

```markdown
## 배경
왜 이 변경이 필요한가 (이슈 링크가 있으면 포함)

## 변경 내용
- 핵심 변경 3~5개 (파일 목록이 아니라 동작 기준으로)

## 테스트
- [ ] 실행한 테스트/확인 방법 (실제로 돌린 것만 체크)

## 리뷰 포인트
리뷰어가 특히 봐야 할 곳, 의도적으로 안 한 것
```

## 규칙
- 제목은 70자 이내, 커밋 컨벤션과 맞춘다
- **실행하지 않은 테스트를 체크하지 않는다**
- `gh pr create`는 사용자가 승인한 뒤에만 실행한다
